Data Mining Midterm Project: Classification of Simple Features
Overview
This project demonstrates the classification of three simple features from the Iris dataset using two different machine learning models: K-Nearest Neighbors (KNN) and a Deep Learning model. The goal is to compare the decision boundaries generated by each model for the task of classifying data points based on two features of the Iris dataset.

Dataset
The Iris dataset is a popular dataset for classification tasks. It contains 150 samples of iris flowers, with each sample having four features: sepal length, sepal width, petal length, and petal width. For this project, we use only the first two features: sepal length and sepal width, to classify the flowers into three categories: Iris Setosa, Iris Versicolour, and Iris Virginica.

Steps Involved
1. Data Preparation
We load the Iris dataset using sklearn.datasets.load_iris().

The feature matrix X contains the first two columns (sepal length and sepal width) of the dataset.

The target vector y contains the class labels (0, 1, or 2) for each sample.

We convert the target vector y into a categorical format using to_categorical() from Keras, which transforms it into a one-hot encoded matrix for use with deep learning.

2. Data Splitting
The dataset is split into training and testing sets using train_test_split() from sklearn.model_selection, with 70% of the data used for training and 30% reserved for testing.

3. K-Nearest Neighbors (KNN) Classifier
We create an instance of the KNN classifier with 3 neighbors using KNeighborsClassifier().

The model is trained on the training data (X_train, y_train) using the fit() method.

The KNN classifier is used to classify the data points and generate a decision boundary.

4. Deep Learning Model
We create a simple neural network model using Keras' Sequential() API.

The model consists of two layers:

A dense layer with 10 neurons and ReLU activation for the hidden layer.

A dense layer with 3 neurons and softmax activation for the output layer (corresponding to the 3 classes).

The model is compiled using categorical_crossentropy loss and the adam optimizer.

The model is trained for 50 epochs with a batch size of 10 using model.fit().
